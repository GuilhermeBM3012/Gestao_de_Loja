# Gestão de Loja

Projeto acadêmico desenvolvido em **Java** com integração ao **Oracle Database**, utilizando **JDBC** para conexão e persistência dos dados.

O projeto tem como objetivo aplicar conceitos de **Programação Orientada a Objetos, Banco de Dados, SQL, JDBC, arquitetura em camadas e manipulação de arquivos JSON**.

---

## Tecnologias utilizadas

* **Java 25**
* **Oracle Database 21c XE**
* **JDBC**
* **Maven**
* **Oracle JDBC Driver (ojdbc11)**
* **Gson**
* **Git / GitHub**

---

## Arquitetura do projeto

O projeto foi organizado utilizando uma arquitetura em camadas:

```text
Application
    ↓
Presentation
    ↓
Service
    ↓
Repository
    ↓
Infrastructure
    ↓
Oracle Database
```

### Principais pacotes

```text
br.com.fiap
├── Application
├── Domain
├── Exception
├── Infrastructure
├── Repository
├── Service
├── Presentation
└── Util
```

### Responsabilidade de cada camada

**Application**

* Ponto de entrada da aplicação.
* Inicialização do sistema.

**Presentation**

* Menus e interação com o usuário.
* Utilização do `Scanner`.
* Exibição de informações e mensagens.

**Service**

* Regras de negócio.
* Validações dos dados.
* Verificação de entidades relacionadas.

**Repository**

* Comunicação com o banco de dados.
* Operações CRUD.
* Execução de comandos SQL utilizando `PreparedStatement`.

**Infrastructure**

* Configuração e conexão com o Oracle Database.

**Domain**

* Classes que representam as entidades do sistema.

**Exception**

* Exceções utilizadas para tratar situações específicas da aplicação.

**Util**

* Funcionalidades auxiliares, como manipulação de JSON e arquivos.

## Entidades

O banco de dados possui as seguintes entidades:

* Cliente
* Fornecedor
* Funcionário
* Produto
* Pedido
* Item do Pedido
* Pagamento

### Relacionamentos

```text
Fornecedor
    │
    └── Produto
            │
            └── ItemPedido
                    │
                    └── Pedido
                       ├── Cliente
                       └── Funcionário
                            │
                            └── Pagamento
```

De forma simplificada:

* Um fornecedor pode possuir vários produtos.
* Um cliente pode realizar vários pedidos.
* Um funcionário pode estar relacionado a vários pedidos.
* Um pedido possui vários itens.
* Um item pertence a um produto.
* Um pedido pode possuir um pagamento.

## SQL

O projeto também utiliza recursos do Oracle Database além do CRUD tradicional.

### Views

Foram utilizadas **Views** para facilitar consultas envolvendo múltiplas tabelas.

### Functions

Foi criada uma função para calcular o valor total dos itens de um pedido:

```sql
fn_valor_pedido
```

Exemplo:

```sql
SELECT fn_valor_pedido(1)
FROM dual;
```

### Procedures

Foi criada uma procedure para atualização do status de um pedido:

```sql
pr_atualizar_status_pedido
```

Exemplo:

```sql
EXEC pr_atualizar_status_pedido(1, 'PAGO');
```

### Triggers

Foi criado um trigger para atualizar automaticamente o estoque quando um novo item é inserido em um pedido:

```sql
CREATE OR REPLACE TRIGGER Atualizar_estoque
AFTER INSERT ON item_pedido
FOR EACH ROW
BEGIN

    UPDATE produto
    SET quantidade_estoque = quantidade_estoque - :NEW.quantidade
    WHERE id_produto = :NEW.id_produto;

END;
/
```

## Conexão com o banco

A conexão com o Oracle é realizada através do JDBC.

Exemplo da URL utilizada no ambiente local:

```text
jdbc:oracle:thin:@localhost:1521/XEPDB1
```

A classe responsável pela conexão está localizada em:

```text
br.com.fiap.Infrastructure.ConexaoBD
```

## Como executar o projeto

### 1. Pré-requisitos

É necessário ter instalado:

* Java 25
* Maven
* Oracle Database 21c XE
* IDE de sua preferência

### 2. Configurar o banco

Execute os scripts da pasta `sql` na seguinte ordem:

```text
01_tabelas.sql
02_inserts.sql
03_views.sql
04_functions.sql
05_procedures.sql
06_triggers.sql
```

### 3. Configurar a conexão

Verifique as credenciais utilizadas na classe:

```text
ConexaoBD
```

A conexão deve apontar para o banco Oracle configurado localmente.

### 4. Executar o projeto

Execute a classe:

```text
br.com.fiap.Application.Application
```
